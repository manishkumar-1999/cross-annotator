Convert the species names in an abundance matrix from one taxonomy database to another.

Runs entirely in your browser. Your file is never uploaded anywhere.

Result

“Case only” species have the same name in the target database, written with different upper/lower case. They keep the spelling from your file and are not counted as converted.

The WGS mapping files list only species whose names differ between the two databases, so many “not found” species is normal: they already have the same name.

How it works

      
    
        
  1. Each species column name is looked up in the mapping file for the databases you chose: left column = source name, right column = target name.
    2. 
        
  2. Found names are replaced with the target name. Names that differ only in upper/lower case keep your spelling (“case only”). Names that are not found keep their original name.
    3. 
        
  3. Columns that end up with the same name are added together, sample by sample, into one column.
    4. 
        
  4. You get the converted matrix (same samples, same layout) and a summary of what changed.
    5.
